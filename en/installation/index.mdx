This guide covers the full installation of the Voltic Smart Room Control system in hotel rooms. It includes prerequisites, mounting instructions for each device, electrical connections, and platform verification.

<Warning>
  This guide is a living document. It is updated regularly with new recommendations, best practices, and devices. Always consult it before performing any installation.
</Warning>

## Recommended installation order

<Steps>
  <Step title="Install Voltic Hubs and Zigbee Repeaters">
    This step is fundamental to ensure connectivity for all devices within the rooms.
  </Step>
  <Step title="Verify kit numbering per room">
    Each kit is preconfigured for a specific room. It cannot be swapped between rooms.
  </Step>
  <Step title="Mount devices inside each room">
    Install the Voltic Switch, FrostLine, contact sensors, and presence sensors in each room.
  </Step>
  <Step title="Validate on the platform once each floor is finished">
    Go to [app.voltic.es](https://app.voltic.es) to verify that all devices are synced and reporting correctly.
  </Step>
</Steps>
