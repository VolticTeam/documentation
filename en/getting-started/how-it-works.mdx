Voltic Smart Room Control is a BMS (Building Management System) designed specifically for hotel rooms. It combines wireless Zigbee sensors, a connectivity hub, and a cloud platform to automate climate control and lighting based on the actual occupancy of each room.

## System components

| Device | Function |
| --- | --- |
| **VolticHub** | Zigbee coordinator. Connects via Ethernet or Wi-Fi and centralizes devices for its floor. |
| **Voltic FrostLine** | Smart digital thermostat. Controls the room fan coil according to the validated diagram; the usual profile is 2-pipe / 2-way, with 4-pipe or hydronic underfloor heating when the project, version, and firmware support it. |
| **Voltic Switch** | Smart contactor in the electrical panel. Controls lighting and TV subcircuits. |
| **Presence sensor (PIR)** | Detects whether people are in the room or bathroom. |
| **Contact sensor** | Detects whether a window or door is open or closed. |

## How automation works

<Steps>
  <Step title="The Hub detects sensor events">
    The VolticHub receives real-time status from Zigbee sensors: presence in the room, window openings, and ambient temperature.
  </Step>
  <Step title="The system evaluates occupancy and window status">
    The system applies the selected mode. In ECO, if no presence is detected for the configured time (default: 5 minutes), it turns HVAC off; in COMFORT, it maintains the setpoint even when no presence is detected. If an open window is detected, HVAC turns off according to the configured window timer.
  </Step>
  <Step title="Automations adjust HVAC and lighting">
    The Voltic FrostLine regulates the fan coil according to the setpoint of the active mode (ECO or COMFORT). The Voltic Switch cuts or restores power to lighting and TV subcircuits.
  </Step>
  <Step title="Data is reported to the platform">
    All activity is logged in [app.voltic.es](https://app.voltic.es), where you can monitor room status, configure automations, and review energy consumption.
  </Step>
</Steps>

## Zigbee network

All sensors and actuators communicate with the VolticHub using the Zigbee protocol (2.4 GHz band). The Hub uses **Zigbee channel 25** by default, which can overlap with **Wi-Fi channel 11**. Configure the hotel's access points to avoid channel 11 and reduce collisions and interference.

<Note>
  The official topology is one VolticHub per floor. As a reference, each Hub can manage approximately 150 devices and should be assigned 10–15 rooms on that floor. Rooms must be on the same floor; add repeaters and, only when the coverage survey requires it, an additional Hub.
</Note>

## Energy savings

Hotels that operate the Voltic system correctly can achieve **energy savings of up to 30% in guest rooms**, thanks to presence-based automation and proper temperature configuration. This is an internal Voltic figure; see [voltic.es](https://voltic.es) for more information.
