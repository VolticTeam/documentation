Esta guía cubre la instalación completa del sistema Voltic Smart Room Control en habitaciones de hotel. Incluye requisitos previos, montaje de cada dispositivo, conexiones eléctricas y verificación en la plataforma.

<Warning>
  Esta guía es un documento vivo. Se actualiza regularmente con nuevas recomendaciones, buenas prácticas y dispositivos. Consúltala siempre antes de realizar cualquier instalación.
</Warning>

## Orden de instalación recomendado

<Steps>
  <Step title="Instalar Voltic Hubs y Repetidores Zigbee">
    Este paso es fundamental para garantizar la conectividad de todos los dispositivos dentro de las habitaciones.
  </Step>
  <Step title="Verificar numeración de kits por habitación">
    Cada kit está preconfigurado para una habitación concreta. No puede intercambiarse entre habitaciones.
  </Step>
  <Step title="Montar dispositivos dentro de cada habitación">
    Instala el Voltic Switch, FrostLine, sensores de contacto y sensores de presencia en cada habitación.
  </Step>
  <Step title="Validar en plataforma una vez terminada cada planta">
    Accede a [app.voltic.es](https://app.voltic.es) para verificar que todos los dispositivos están sincronizados y reportando correctamente.
  </Step>
</Steps>
